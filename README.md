# Instagram Clone - React - Driven Bootcamp 📸

## Description 📝

An Instagram clone rebuilt with React, featuring interactive posts with like and save functionality. A step up from the HTML/CSS version, this project focuses on component-based architecture, state management and React hooks.

🔗 **Live Demo:** [instagram-clone-react-gules.vercel.app](https://instagram-clone-react-gules.vercel.app/)

---

## Tech Stack 🛠️

- React
- JavaScript
- CSS3
- Ionicons
- Git & GitHub
- Vercel

---

## Features 🚀

- Like and unlike posts with counter update
- Save and unsave posts
- Double-click on image to like
- Stories section with horizontal scroll
- Sidebar with profile suggestions
- Responsive layout
